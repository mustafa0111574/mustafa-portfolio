# Mustafa Saady — Premium Portfolio

## How to use
1. Extract this ZIP.
2. Open the extracted `mustafa-portfolio-premium` folder in VS Code.
3. Copy `index.html`, `css/style.css`, and `js/main.js` into your existing portfolio repository, replacing the old files.
4. Keep your existing `assets/images` folder unchanged. The new page uses the same image paths already present in your current HTML.
5. Run with Live Server and check desktop + mobile before pushing to GitHub.

## Important
- Keep `assets/images/1717794885744.jpg` and the three DocCare screenshots at their existing paths.
- If a photo or screenshot does not appear, check that the filename and capitalization match exactly.
- The role text animation and scroll reveals are implemented in `js/main.js`.
- The site respects the visitor's reduced-motion accessibility preference.
